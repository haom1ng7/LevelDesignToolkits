# 项目设计上下文（可选）

本 Skill 决定"终末地视觉语言如何运用"，但不保存某个具体项目已经批准的主题、组件与例外。项目级记忆应放在该项目自己的文件里，例如仓库根目录的 `endfield-design-context.md`。

## 何时创建

- **只在用户明确要求**"保存 / 记录 / 锁定本项目的设计决定"时创建或更新；不要在普通 Build 任务中自动生成。
- 创建或更新前，先说明将写入哪些字段；已有文件时只追加或修改被批准的条目。
- 项目特例（特殊画布、品牌色、禁用母题）只写入此文件，**永远不回写**通用 Skill 的规则或证据文件。

## 读取时机

后续任务若检测到项目中已有 `endfield-design-context.md`，先读取它再做设计决定。

优先级边界：项目上下文**可以**覆盖视觉默认值、主题锚、token、组件选择、家族选择和已批准的项目例外，覆盖时指出与本 Skill 的差异；**用户在当前任务中的明确要求始终优先于项目上下文**；项目上下文**不得**覆盖 Study 的写入授权、官方资产与版权边界、数据真实性、可访问性与基本可用性要求，也不改变本 Skill 的触发范围。

## 推荐字段

```markdown
# <项目名> · Endfield Design Context

## 项目与受众
- 产品类型 / 发布渠道 / 主要读者 / 使用频率

## 家族选择
- 主家族：<例：数据简报> · 次家族：<例：档案型>
- 各命令/页面 → 家族 映射表

## 主题锚与语义色
- 主题锚：<系统黄 / 角色色 / 品牌色>
- 项目语义色映射（如 胜/负、职业色、稀有度）

## 已批准的 token 与组件
- 画布宽度 / 字体栈 / 间距基线
- 组件清单（名称 → 用途 → 家族来源）

## 禁用母题与例外
- 本项目明确不用的母题；经批准的规则例外及理由

## 响应式与导出
- 断点策略 / 导出参数（宽、倍率、格式）

## 决策记录
- <日期> <决定> <理由> <批准人>

## 未决问题
```

## 与 Study 的关系

Study 提炼的是官方素材的规律，写入 Skill 需要单独授权；项目上下文保存的是项目自己的选择，两者不混用。
