# 关卡设计工具箱 · Level Design Toolkits

面向关卡策划的轻量绘图工具，用一份工程整理空间布局、行动路线和游玩节奏。

支持空间三视图、楼层与组件编辑、节奏／压力曲线，以及图片和三维模型导出。无需账号，可离线使用；网页版采用单文件 HTML，Windows 版复用同一套编辑器，工程通过 JSON 文件互通。

![空间图立体视图示例](docs/空间图_立体.png)

## 开始使用

| 方式 | 使用方法 |
| --- | --- |
| 离线网页 | 下载并解压项目，使用桌面版 Chrome 或 Edge 打开 `dist/index.html`，无需安装开发依赖。 |
| Windows 便携版 | 若仓库 Releases 已提供发行附件，下载 `LevelDesignToolkits-1.0.0-Windows-x64.exe` 后双击运行。适用于 Windows 10／11 x64，无需安装，首次启动会解包到临时目录。目录版 ZIP 则需完整解压后运行。 |
| 在线网页 | 若维护者已部署网站，从仓库 About 或 Settings → Pages 获取实际网址，在浏览器中打开。 |

第一次使用可以按以下步骤开始：

1. 新建“空间图”或“曲线图”，也可通过“打开工程”载入示例 JSON。
2. 空间图中拖拽创建平面、墙壁，放置楼梯并添加路线；曲线图中拖动节点、编辑阶段和事件。
3. 点击“下载工程”保存可继续编辑的 JSON；需要分享或导入其他软件时，点击“导出图稿”选择格式。

示例工程：[两层小楼](data/two-storey-house.json) · [空间与曲线](data/qa-project.json)。请先下载 JSON，再在工具中打开。

顶部“使用说明”提供分组教程和 7 段操作演示。也可阅读[图文教程](docs/使用说明.md)，或下载[离线教程 HTML](docs/使用说明.html)后打开。

## 空间布局与节奏设计

### 空间图

- **三视图联动**：在平面图、立面图和立体图之间切换，从不同方向编辑同一组组件。
- **楼层与组件**：管理楼层高度、显示和锁定；创建平面、墙壁、宿主空洞、楼梯、爬梯、旋转楼梯，以及文字、路线和标记。
- **形状与变换**：调整轮廓顶点、尺寸和方向；支持组件吸附、顶点对齐、编组、多选、复制及撤销重做。
- **立体编辑**：W 沿世界轴或平面移动，E 绕三轴旋转，R 调整单个实体尺寸；拖动角点时固定对角点，Alt 拖动手柄可复制组件。
- **按网格搭建**：在“图稿设置 → 网格”设置“每格/cm”，默认 100 厘米。网格显示与网格吸附可分别开关；开启吸附后，创建、移动和尺寸编辑按当前网格约束，Ctrl 可临时暂停。

立体图支持多实体一起移动和旋转；独立轮廓顶点与空洞编辑在平面图或立面图中完成。空洞依附宿主，随宿主变换。

### 曲线图

绘制节奏或压力曲线，通过拖动节点调整事件位置与曲线高低；编辑阶段、事件名称、图表标题和坐标轴，并拖动排列事件名称。一个工程可以同时包含多张空间图和曲线图，分别命名、复制和管理。

![节奏曲线示例](docs/曲线图_总览.png)

界面支持浅色／深色主题；窄屏下通过底部入口切换“图稿与工具”“编辑画布”“属性与设置”。界面主题独立保存，不改变图稿背景或导出颜色。复杂绘图建议使用桌面浏览器和鼠标。

## 保存与导出

| 格式 | 用途与范围 |
| --- | --- |
| JSON | 保存整个工程，保留可编辑数据，用于备份和跨端转移；通过“打开工程”恢复。 |
| PNG | 导出当前图稿的图片，支持倍率设置，以及“完整图稿”或“当前视野”取景。 |
| SVG | 导出当前图稿的矢量图，同样支持完整图稿或当前视野。 |
| FBX | 空间图三维模型，采用二进制 FBX 7.4，包含三角网格、法线、基础颜色和透明度，单位为厘米。 |
| OBJ | 空间图三维几何，包含三角网格和法线，不生成 MTL 材质文件。 |

FBX／OBJ 导出所有可见楼层中的可见实体，保留宿主空洞、位置、旋转和楼层高度；不受当前视图、选中范围或预览取景裁切影响。两者均为 Z 轴向上、坐标数值 1:1，不输出文字、路线、标记、网格或编辑辅助线。曲线图使用 PNG／SVG 导出。

工具适合关卡方案草图、空间关系说明和节奏沟通。导出的模型可用于后续搭建参考，复杂建模与细节制作仍需在专门软件中完成。

## 常用操作

| 操作 | 鼠标或快捷键 |
| --- | --- |
| 缩放／平移画面 | 滚轮／按住中键拖动，或空格＋拖动 |
| 转动立体视角 | 在立体图空白处拖动 |
| 移动／旋转／调整大小 | W／E／R，S 兼容大小工具 |
| 绘制路线 | L，Enter 或双击结束 |
| 撤销／重做 | Ctrl＋Z／Ctrl＋Shift＋Z |
| 复制／粘贴 | Ctrl＋C／Ctrl＋V |
| 编组／解组 | Ctrl＋G／Ctrl＋Shift＋G |
| 取消当前操作 | Esc |

工具快捷键请使用英文输入法；中文文字可正常输入，文字编辑期间不会切换工具。完整操作见[使用说明](docs/使用说明.md)。

## 数据保存与隐私

自动暂存保存在当前浏览器或桌面程序的本机配置中，没有云端同步。更换浏览器、网页地址、电脑或清理本地数据前，请先“下载工程”保存 JSON；网页和桌面版之间也通过 JSON 转移工程。

程序没有账号、遥测或云端工程服务，图稿不会自动上传。网页的脚本、样式、字体和教程媒体均内嵌在 HTML 中，离线使用无需联网；访问托管网站时，托管平台仍会接收正常的网页访问请求。

## 本地开发

环境要求：**Node.js 24、npm、Python 3**。在项目根目录执行：

```sh
npm ci
npm run build
npm test
```

`build` 将 `src/` 源码和资源拼装为 `dist/index.html`，可直接离线打开，也可作为静态网站部署，无需后端。`test` 运行 15 组自动回归，多数检查读取构建产物，因此修改源码后应先构建再测试。

网页使用原生 JavaScript、HTML、CSS 和 SVG，无前端框架或第三方运行时脚本。npm 依赖用于构建、测试和 Electron 桌面封装。首次安装依赖、下载桌面构建工具需要联网。

### 目录导航

| 路径 | 内容 |
| --- | --- |
| `src/` | 模型、几何、渲染、交互与界面源码 |
| `src/help/`、`src/fonts/` | 教程内容、演示媒体和本地字体及许可 |
| `data/` | 正式空工程种子与示例工程 |
| `desktop/` | Electron 主进程、包配置和图标 |
| `tools/` | 网页构建、教程生成、桌面封装和发布整理脚本 |
| `tests/` | 自动回归、浏览器与桌面检查脚本及测试夹具 |
| `dist/` | 构建后的离线网页 |
| `docs/` | 用户教程、示例图片和发布说明 |
| `logs/CHANGELOG.md` | 项目变更记录 |
| `.codex/` | 项目协作上下文、规则、技能与 hooks |

源码从 `src/` 修改，不要直接维护生成后的 HTML。普通脚本按固定顺序拼装，交互片段共享主闭包；模块关系见[项目上下文](.codex/project-context.md)，协作规则见 [AGENTS.md](AGENTS.md)。

### 更新教程

`src/help/content.json` 是内置帮助与外部教程的共同内容源。修改内容或媒体后执行：

```sh
npm run manual
npm run build
```

前者生成 `docs/使用说明.md` 和 `docs/使用说明.html`，后者更新内置教程。构建所需的 GIF、PNG 和字体必须保留。

### Windows 封装与发布

补齐封装输入后，在 Windows 执行：

```sh
npm run package:portable
python -X utf8 tools/package-release.py
```

`package:portable` 依次构建网页、目录版和单文件便携版，输出至 `.build/desktop/` 和 `.build/portable/`。发布脚本将程序、离线网页、教程、示例、源码包和 SHA-256 校验值整理到 `release/`，不会自动上传或部署。便携 EXE 包含完整 Electron 运行时，因此体积大于网页文件。

当前源码目录的封装与发布输入尚不完整：桌面脚本引用的 `docs/导出图稿_预览.png`、`docs/事件名称排序_拖动中.png` 缺失；源码归档清单仍引用不存在的根目录 `CHANGELOG.md` 和 `.gitattributes`，实际日志位于 `logs/CHANGELOG.md`。执行前需补齐资源并校正归档清单。

当前目录也未包含 `.github/workflows/`，不能直接依赖文档中提到的 Pages／Windows 工作流。静态部署可使用 `dist/index.html`；若采用 GitHub Actions，需要先补齐对应配置。操作参考[发布指南](docs/GitHub发布指南.md)。

### 可重新生成的文件

`node_modules/`、`.build/`、`qa/`、`dist/build-report.json` 和 `dist/qa.html` 用于依赖、临时构建或检查输出，可按需清理。删除依赖后先执行 `npm ci`；保留 `dist/index.html` 即可继续使用离线网页。不要将个人工程和暂存数据作为正式启动种子。
