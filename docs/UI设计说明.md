# v1.2 界面设计

设计约定：`endfield × maximal`（4 级极繁）。以关卡创作为主任务，采用灰白工作面、炭黑操作区、信号黄动作与切角，覆盖启动、空间三视图、曲线编排、属性、导出和帮助。保留原生 JavaScript、110% 界面比例和单文件离线运行。

## 证据与来源

依据项目 Ark UI 技能 `references/source-ledger.md` 已记录的 [Endfield 官网](https://endfield.hypergryph.com/) 浅色竖轨、炭黑停靠区、黄色动作、切角和大型章节编号，以及 [角色目录](https://endfield.hypergryph.com/operator) 的编号、筛选和双语标题模式。这是对公开高层模式的原创转译；本次没有重新抓取生产站点，也没有嵌入官方游戏图片、标志、字体或生产代码。

中文界面采用与思源黑体同源的 Noto Sans SC 可变字体，以方正字面和清晰直线呼应工业工作台。标题沿用 700–800 字重、按钮沿用 600 字重、正文使用常规字重，均由字体的真实连续字重呈现。英文标签、编号和常用控件内的拉丁字符继续使用 Saira。两款字体及 OFL 许可随离线单页嵌入；中文字体子集覆盖 GB2312、现有界面文案及常用标点，生僻字回退到微软雅黑、苹方等系统字体。画布、图内文字编辑及图稿导出沿用原字体，避免改变既有图稿排版。字体来源与处理方式见 `src/fonts/README.md`。

## 信息归属与模式构图

- 全局：顶栏管理文件和历史；左栏直接管理图稿、绘图工具和组件；右栏编辑属性。工作区铺满顶栏下方，移除独立 LD/ 导航列与底部状态行。英文小标签只保留英文，主要中文标题与操作保持清晰；图稿数量、组件数量、事件数量仅由各自原有位置管理。
- 启动：大型两行标题、工程网格、方向切线、非对称明暗模板与矢量图解构成五层舞台。卡片仅保留类型名称，右上使用短切角，空间示意图移除辅助虚线。宽屏两张卡片等高并保持上下错位；紧凑窗口按原有方式堆叠或对齐。两个按钮直接创建空间图或曲线图，正式种子保持空工程。
- 空间：标题左侧两位编号表示当前图稿在工程列表中的顺序，空工程显示 00；空间图与曲线图共用顺序，新增、复制、删除及撤销重做后同步更新，切换视图保持同一编号。平面、立面、立体驱动模式标题和视图基线长度；楼层列表与视图按钮显示真实当前状态。三视图、参考线与箭头、吸附、背景、取景、立面与创建选项合并为单行工具栏，移除“显示”及分隔线；三视图与立面/创建上下文选项靠左，参考线、吸附、背景和取景等常用选项靠右，曲线图隐藏空间选项后仍保持常用选项靠右。空间不足时在工具栏内横向滚动，键盘聚焦自动显示对应控件。立体相机操作停靠画布下缘。画布四周不绘制装饰取景框、刻度或角线。
- 曲线：独立节奏标题和斜体图稿编号、炭黑属性标题带与阶段/事件设置，画布四周同样不绘制装饰线框。图稿内容与颜色仍由用户工程管理。
- 选择：真实组件或事件选择切换右栏标题底边强调色与属性状态；“属性与设置”标题右侧不显示装饰箭头。主题、导航和构图状态不进入 JSON 和撤销记录。
- 顶点编辑：以轮廓为主视觉，顶点使用骨白切角方形、炭黑描边和中心定位点；悬停变为信号黄，当前顶点增加对角角标。边中点使用更轻的菱形加号，表示插入节点。节点保持固定屏幕尺寸，外围保留 20px 命中范围；骨白隔离线保证在用户设置的深浅画布和组件填色上可辨认，编辑手柄不进入导出。
- 输出与阅读：导出采用大预览加独立动作列；帮助采用炭黑标题、编号目录与较宽正文，移动端分别重排为纵向设置和章节选择器。

## 动效、响应式与性能

启动标题、模板依次揭示；真实文档/视图/面板切换触发一次 280ms 标题裁切，模板悬停与弹窗使用同一机械缓动。没有持续计时器、帧循环或环境动画。颜色与深度变量分开维护；原有编辑逻辑和导出渲染保持独立。

990px 以下左右栏重排为底部三个完整工作面；短竖屏缩短标题和横向模板，优先展示两个创建入口；短横屏以左右分区重排标题与模板。工具栏在所有尺寸下保持单行，为画布保留高度，窄窗口以横向滚动访问全部选项。内容密集的属性与短窗口局部降至 complex，保留全部必要控件与标签。`prefers-reduced-motion` 移除 CSS 及脚本触发的动效，保持相同内容和状态。

使用原生按钮、对话框、可见焦点、跳到画布链接和 `inert` 隐藏面板。文字对比度、主题隔离、键盘、真实编辑与下载使用 Chrome 验证。没有新增运行时依赖、远程资源或网络访问。
