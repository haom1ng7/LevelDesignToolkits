# 编辑器行为规则

适用于模型、几何、选择、拖拽、属性面板、曲线和导出功能。以下是现有行为；任务明确要求改变某项时，同时调整对应界面说明和回归预期。

- 沿用现有 `mutate`、`history` 及拖拽提交/取消流程，保持一次用户操作的撤销语义。覆盖失败回滚、取消、撤销和重做，避免一次拖动拆成大量历史记录。
- 空洞依附宿主，复制、删除和移动时检查宿主关系；涉及编组和整层操作时同时检查关联对象及当前选择状态。
- 空间图共享同一模型。修改平面、立面或立体图操作时，检查另外两个视图及楼层/可见性过滤，不另存互不一致的几何副本。
- 现有立体图实体支持 W 世界轴/平面移动及 Alt 拖动复制、E 世界三轴刚体旋转；R 通过本地角点调整单实体长宽高，对角点固定。多实体/整层可移动和旋转，独立轮廓顶点编辑主要在平面/立面完成。文字和路线有独立编辑路径，不按普通实体统一处理。
- 移动、旋转和大小吸附使用不同的手势求解；调整其中一项时保留用户主动控制的维度，并检查 Ctrl 暂停吸附、隐藏对象、立面深度及楼层范围。
- 曲线事件的位置、阶段归属、标签偏移和排序有关联。修改阶段/刻度时检查事件位置、名称编辑和撤销，避免仅通过属性字段断言行为。
- 中文输入期间保护文字编辑和重命名状态；工具快捷键要检查物理按键与组合键，不能把输入法组合文本误判为工具命令。
- 完整图稿和当前视野导出有不同的相机/尺寸语义。预览缩放不能意外改写输出范围；成品排除选择框、世界手柄和吸附辅助线。
- 异步导出在切换或关闭预览后不下载旧图稿，释放临时对象 URL。文字对比色的临时 Canvas 维持长边和总像素限制。
- 自动暂存按既有键隔离，JSON 用于迁移和长期保存。更改键或工程格式时提供兼容处理，不能默默抛弃用户的已有数据。
