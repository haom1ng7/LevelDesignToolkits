## 对现有规则的修正

**日历稳定的是时间结构。** 旧版「向渊行」的红黑墨刷与新版冰蓝刊头共享类目竖轨、日期锚和错落横幅；因此保留历史观察，将固定红色的概括收窄为主题实例。青色日期块也没有被提升成通用数据色。

**首页可以由版本场景接管。** 当前窄屏首屏是青紫雪域和角色画面，顶部仍有白色导航外壳。墨迹黑烟保留为旧版本可选语法；新版干员、LORE 与玩法分节的内容顺序分别登记，没有提炼成通用页面骨架。

**编辑主题与 UI 状态分开。** 周边目录的青色价格底线、问答的紫色/青色气泡承担系列排印与角色区分。它们不改写系统 UI 的黄色进度、蓝色量值图表或橙色强调语义。

**补充四类编辑体裁。** 参与招募与奖励说明、商品目录、主持问答与幕后讲解、连载漫画，均进入编辑家族的条件层。另补充纯场景前瞻用法。提弗洛斯备忘与官网部分分节再次支持既有结构；本轮新增全局视觉规则 **0 条**。
