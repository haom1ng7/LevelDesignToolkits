# 静态海报、攻略与运营长图

静态物料首先是编辑设计：阅读顺序、内容节奏和图文关系决定结构。不要因为产出是"一张图"就自动使用固定画布、品牌条或三段页眉。先选体裁，再定版式；同一系列刊物维持自己的刊头系统，不同体裁不共享固定零件。

## 选择编辑体裁

按内容选择一种主体裁，长图可按章节切换密度，但体裁气质应贯穿全篇。

### 档案型

适合人物、装备、地区或机制介绍。

- 大主体图或名称作为视觉锚；身份、属性、引文、能力按优先级停靠。
- 官方变体：**人物备忘**（主题色接管 + 身份表格 chip + `//` 章节标题 + 访谈问答带 + 留言板卡片 + 手写批注与贴纸 + START/END 起讫标记）；**威胁档案**（竖排大字标题 + 印章/胶带/纸质文件等档案道具 + 中文数字层级竖轨 + 标本卡矩阵 + WARNING 红带 + 向导角色对话条）；**武器/装备档案**（左缘竖排毛笔字刊头 + 规格铭牌排版 + 效果条 + 【】「」引用）。
- 允许角色/地区主题色和展示字体；避免把所有字段排成相同白卡。

### 时间轨型

适合版本日历、活动计划和更新路线。

- 时间是主轴：版本刊头 + 左侧类目竖轨 + 清晰日期锚 + 按起始日错落的活动横幅，形成甘特节奏；每条活动保留自身主题色与类型标签，空档也参与表达时间跨度。
- 刊头与日期锚随版本主题换色，主题色通常来自本版主地区或题材——「雪凇幽梦」的活动集中在雪松林，所以整份日历取雪山的冰蓝/青。已见「向渊行」的红黑白、墨刷与红角标；也见「雪凇幽梦」的冰蓝渐变刊头、青色日期芯片、淡色纹样与斜纹空档（其时间轴上的日期锚仍是黑块 + 红角，下加青色底线）。红色并非日历固定结构色，青色日期芯片也不构成通用数据色。
- 颜色区分主题或类别时要提供文字/图标冗余；日期必须最易扫描。
- 避免把时间轴退化成普通卡片列表。

### 系统图解型

适合工业机制、玩法、生产流程和技能关系。

- 步骤、依赖或流向支配版式；主图、局部放大、编号、连接线和解释文字形成连续阅读路径。
- 官方变体：**说明书体**——编号章节带（001、002…）+ 截图/渲染证据 + 红笔手写批注圈点 + 黄色荧光笔划重点；读起来像被人批注过的教材。批注层只用于确实需要强调的少数句子。
- 标注色可以按主题选择，真实流程线强于装饰线；避免只有大标题与多张平行说明卡。

### 前瞻/回顾卷轴型

适合版本故事、玩法预告、活动串烧和赛季回顾。

- 全幅截图或画面竖向堆叠，章节标题带（如 ‹‹ 标题 ››）作为唯一分隔，chrome 极简。
- 活动串烧变体：每个活动区块保留自身识别色与纹理（水墨、故障、拼贴、扁平图形互不相同），日期 chip 与类型标签保持恒定语法。
- 通用零件：签到=01–07 日签卡行；通行证=梯度奖励卡行；继承关系用 » 箭头链；更新日志用 NEW 章节 chip + 物品卡行；系统优化用"类目色签 + 截图上数字圈标注 + 说明条"。
- 每一屏只保留一个主结论或主动作。

### 期刊/杂志型

适合系列攻略、地区导览、社区栏目。

- 固定刊头系统（标志 + VOL 编号 + 出品方落款）跨期稳定；吉祥物或主持角色可贯穿版面。
- 地点/主题标签截图卡、清单行带（店铺、条目）、旁批与贴纸构成正文肌理。
- 避免一期换一套刊头；系列感本身是设计资产。

### 通告型

适合测试公告、规则说明、FAQ、收费说明。

- 标签行（深色 chip + 值）陈列关键信息；日期给最大字号；Q&A 用 Q 方块 + 粗体问题；关键承诺用荧光笔标注；价格/规则用并列白卡。
- 基调通常是系统黄黑白；语气克制，不加叙事装饰。

### 参与招募与奖励说明型

适合社区征集、校园活动、摄影投稿和参与指引；与正式测试、收费通告区分。

- 先呈现参与主题与吸引点，再按日期、资格、步骤、奖励、补充规则组织内容；限时与常驻内容分别标明。
- 高校活动变体：黄/奶白/青色接管，大号描边标题与 Q 版群像建立亲近感；奖励集中在纸框或照片框中，步骤用黑色章头与少量荧光笔标注。只在这种参与语境使用贴纸、彩屑与活泼胶囊。
- 摄影征集变体：场景横幅承担吸引，正文承载规则，界面示意与奖励图分别补充说明；不必把整篇帖子压进一张超长海报。

### 商品目录型

适合周边上新、产品系列介绍与实物展示；持续筛选或购买操作转用仓库/商城家族。

- 用「系列入口 → 活动说明 → 商品详情 → 实物展示」分层。单件大图建立主次，商品名与价格在稳定位置配对，再放包装、本体、套装清单和局部特写；不用等大的商品卡覆盖全部内容。
- 实物展示允许连续的大幅摄影，仅保留小型系列标签与必要注脚。拍摄布景、商品自身包装、外层目录版式分开分析。
- 「雪凇夜泊」样本的冰蓝纸面、深蓝展示字、青色价格底线与品红微标属于系列主题；其中黄黑证卡包装不要求外层海报也换黄黑。

### 主持问答与幕后讲解型

适合人物采访、开发访谈与制作过程说明。

- 主持人与嘉宾用头像、姓名/身份和问答顺序区分，不能只靠气泡颜色。固定栏目刊头可以保留，角色主题色可随嘉宾改变。
- 人物 Q&A 变体：大幅 Q 版角色与粗体问答刊头开场；每组问题置于带黑色顶栏的白色框中，主题色提问条与浅灰回答分开，点状分隔帮助扫描。
- 幕后讲解变体：主持提问 → 部门/岗位答复 → 对应截图或过程图 → 下一问。长回答以阅读列组织，局部纸张叠层、括号图注与表情贴纸调节节奏；动图只承担需要比较或演示的局部信息。
- 社区问答长图里的气泡与播放符号属于编辑表达，不能直接据此推断游戏聊天组件或真实可点击控件。

### 连载漫画型

适合轻叙事与角色日常连载，属于编辑物料的条件体裁。

- 封面承担系列名、话数与当期视觉；内页以分镜大小、对白和留白安排阅读节奏。话数与页码保持低干扰，封面技术纹理不必延续到每个分镜。
- 《加油吧！终末地》第 12 话可见 Q 版造型、手绘边框、圆润对白框与明亮封面；这是该系列的表达，不能外推为所有官方漫画或功能 UI 的固定画风。

### 数据简报型

适合排行榜、统计、战报和周报。

- 先选主结论，再决定表格、条形、分布或排名。
- 官方数据页范式可迁移：深色数据行带 + 行内小图表 + 语义数字色（蓝=产出、黄=消耗、红=超支）。
- 数值使用 tabular figures；技术微标与装饰不得冒充真实指标。
- 数据简报也应按结论和阅读任务重新设计，不套用现成的通用报表模板。

## 页面节奏

- 首屏回答"这是什么、为什么重要、从哪里开始读"。标题位置可左、右、纵向或嵌入主体，不固定为品牌行加括号标题。
- 长图每完成一个信息阶段就改变密度、背景平面、图像比例或章节标记，不必固定每三张卡插黄色带。
- 在大图、密集数据和正文之间留出真正的换气区。留白本身可以是不对称构图的一部分。
- 页脚只在需要来源、版权、版本或行动入口时出现；样式服从整张物料（END 标记、落款、法务小字都是可选件）。

## 色彩、形状与排印

- 先选主主题色，再定义状态/分类色。系统黄可以保留为导航或关键高亮，但不必存在。
- 涉及系统状态、数据或稀有度时遵循 `SKILL.md` 的颜色角色表；编辑主题可以接管价格、日期或对话的排印强调，如冰蓝系列的青色价格底线。主题用色不改写系统状态语义。
- 形状按内容语义混用：流程节点、人物头像、日期芯片、引文、对话和数据表不需要共享同一角型。
- 功能正文保持清晰；档案和活动标题可以使用更具性格的展示字（毛笔、手写、符文装饰行——符文只作装饰，不承载真实信息）。
- 双语、编号、条码和坐标只在帮助分组、导航或建立档案语气时使用。

## 图片与素材

- 使用用户提供且被授权的角色图、截图、图标和品牌素材；记录来源与裁切需求。
- 图片承担信息时提供文字说明；图片缺失时不能让核心结论消失。
- 生图只负责难以用代码或现有素材表达的主体视觉，文字、日期、数字和小图标后期排版。
- 不把官方截图或角色立绘默认打包进模板。

## 输出尺寸与工程

- 根据发布渠道确定尺寸、像素密度和文件大小，不默认任何历史画布宽度。
- HTML 截图方案在布局确定后读取 `engineering.md`，把其中的固定宽度改为目标画布参数。
- 超长图预先估算浏览器纹理上限和最终文件大小；必要时分章导出。
- 检查字体加载、图片失败、横向溢出、裁切安全区和 PNG 实际尺寸。

## 验收

1. 缩小到手机宽度时，标题、主结论和阅读顺序是否仍清楚？
2. 去除黄色、切角和英文微标后，结构是否仍成立？
3. 体裁是否一致——批注、印章、吉祥物等道具是否只出现在相配的体裁里？
4. 颜色是否区分主题与数据语义，而不是互相冲突？
5. 页面是否因内容产生变化，而不是重复固定页眉、卡片和页脚？
6. 所有数据、日期、素材来源和注脚是否真实可核对？
